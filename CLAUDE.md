# Rules for Claude

## Git

- Commit and push as me: `Omi Khan <mehboobehsankhan@gmail.com>`. Never as Claude.
- No `Co-Authored-By`, `Claude-Session`, "Generated with Claude Code" or any other AI attribution in commits, PRs or comments.
- Push straight to `main` in this repo. Don't create session branches with random names (like `omi/dreamy-ritchie-xxxx`).
- If a branch is really needed, name it like a developer would, after the change: `fix/readme-links`, `feat/new-section`.
- Commit messages follow the existing history: short, lowercase type prefix (`feat:`, `fix:`, `docs:`, `chore:`), no essay.
