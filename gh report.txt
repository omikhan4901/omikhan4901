## What each one actually is

### 1. `asr` — put this first on the resume
CSE499 capstone: inference-only rescoring for Bangla long-form ASR. Pipeline is VAD chunking → group-aware split → Whisper N-best on Modal GPUs → probability-weighted MBR. Eval numbers: **1-best WER 34.85% → MBR 32.29%**, recovering ~42% of oracle headroom with no weight updates. Demo at [asr-phi.vercel.app](https://asr-phi.vercel.app).

**Why it wins:** real research question, measured results, distributed GPU jobs, web demo. This is the only repo that looks like engineering, not coursework.

**Problems:** still **private**, so recruiters cannot click it. GitHub currently has venv junk (`Scripts/`, `pyvenv.cfg`, `share/`). Course-code repo name (`asr`) undersells it.

**Resume bullet:**
> Built an inference-only Bangla ASR pipeline (Whisper N-best + MBR) that cut WER from 34.85% to 32.29% on 2,271 utterances without fine-tuning; shipped a video-to-SRT demo.

**Resume bullet:**
