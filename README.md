## Featured projects

### 📄 [ResumeX](https://github.com/omikhan4901/cse299) · [resumex.cc](https://resumex.cc)

**A résumé builder where the preview is the real PDF, with an honest ATS check and a whole job search built around it.**

<a href="https://resumex.cc"><img src="https://raw.githubusercontent.com/omikhan4901/cse299/main/docs/marketing/videos/build-wide.gif" alt="Typing in ResumeX: the real PDF updates live" width="100%" /></a>

- The PDF is rendered on every keystroke in a Web Worker (`@react-pdf/renderer` + pdf.js), so what you see is exactly what you download
- 52 templates in 7 categories, most of them generated by a spec-driven template engine
- A deterministic ATS checker: 30+ explainable checks and keyword matching against a job description, all in the browser
- A job-search workspace: a Career Profile, an application board that reads deadlines out of pasted job circulars, and a tailored résumé for every job
- A Gemini assistant grounded in the app's own writing guide; every AI change is shown for review and never invents experience

`Next.js` `React` `Express` `MongoDB` `Gemini` `Cloud Run` · Started as my CSE299 project, now opening as a beta for university students

### 📍 [BondhuKoi](https://github.com/omikhan4901/bondhukoi)

**See which friends are on campus, without anyone seeing where you are.**

<img src="https://raw.githubusercontent.com/omikhan4901/bondhukoi/main/docs/marketing/graphics/play-feature.png" alt="BondhuKoi: see which friends are on campus" width="100%" />

- Friends only ever see "On campus" or "Away". The phone sends a single reading when you cross the campus edge; the server answers "inside or not?" against PostGIS boundaries, stores only the answer and throws the reading away
- Circles for the places you meet: draw your thesis lab or the library on a map, and members see who's there right now
- Arrival alerts that need a yes, quiet hours, one-tap pause and a "Who can see me" screen
- Students only, row-level security in the database, and an admin console that can't see anyone's location

`React Native` `Expo` `Fastify` `Supabase` `PostGIS` `Cloud Run` · Prepared for Google Play

### 🏢 [CompanyMgmt](https://github.com/omikhan4901/companymgmt)

**Attendance, leave and payroll for any business, from a tea stall with two staff to a company with branches. In English and Bangla.**

<img src="https://raw.githubusercontent.com/omikhan4901/companymgmt/main/docs/screenshots/home.png" alt="CompanyMgmt: the owner's home screen" width="100%" />

- Multi-tenant SaaS where isolation is the database's job: forced Postgres row-level security on every tenant table, plus a test that calls every route with another workspace's IDs
- Clock-ins checked against each branch's area on the map, overnight shifts, per-branch time zones and corrections that someone else must approve
- Leave with Bangladesh Labour Act defaults, payroll runs with four-eyes approval, and payslip PDFs in English and Bangla
- Security aimed at OWASP ASVS Level 2, 168 API tests at 92% coverage, and WCAG 2.2 AA checks on every screen

`FastAPI` `PostgreSQL` `Next.js` `TypeScript` `Cloud Run` `OpenTofu` · Rebuilt from scratch from my CSE327 group project
